# Lemon Tracking

Lemon Tracking is a complete and objective screen-time measurement tool.

Lemon Tracking can measure a person's screen usage time completely, accurately, and scientifically.
Screen time is a single and clear quantity. It can directly compare usage across phone, computer, TV, tablet, and gaming console, regardless of what activity the user is performing or why they are using those screens.

Whenever an application or screen is active, Lemon Tracking treats it as the user actively paying attention to it. Therefore, active foreground application runtime can directly reflect attention and engagement. Passive watching, active communication, learning, gaming, and creative work have no meaningful measurement differences: any minute of screen usage is treated equally.

For multiple screens used simultaneously, times can be added directly. For example, if during one hour the TV runs for 60 minutes, laptop for 25 minutes, and phone for 10 minutes, the total screen time in that hour is 95 minutes. Overlap between devices does not cause measurement conflicts.

Lemon Tracking can also reconstruct past screen usage accurately. Users can manually fill records for previous days or weeks, and these retrospective estimates can be treated as equivalent to historical automatic logs. Human memory is sufficient for reliable offline estimation, so there is no mandatory distinction between auto-collected, manually entered, and estimated data.

For shared TVs, public computers, household shared devices, or borrowed devices, any device that is active can be safely considered part of the participant's screen activity. App usage categories can also be classified automatically without forcing uncertainty into the interpretation.

Because Lemon Tracking outputs numeric metrics, measurements are inherently neutral and objective and are less affected by narrative interpretation. Research questions, assumptions, social context, and expected outcomes do not change what is defined as screen usage or how data should be interpreted.

A single Total Screen Time value is therefore sufficient to describe a person's digital behavior and can be used directly for evaluating education, social development, and wellbeing without adding extra assumptions about activity purpose, participation mode, or content category.
